# Исходники LGPL-компонентов

Файлы в этом каталоге входят в соответствующие нативные NuGet-пакеты вместе с бинарниками. `SOURCE_MANIFEST.json` связывает исходный архив с закреплённым коммитом или upstream-архивом и SHA-256. Квитанции в `licenses/provenance/` перечисляют SHA-256 включённых бинарников по RID. Проверка выпуска сопоставляет бинарники с квитанциями нативной сборки и запрещает выпуск при расхождении.

`game-music-emu` и `mpg123` архивированы из закреплённых подмодулей SDL_mixer коммита `72a81869b45e249e8e67102db4e98dd2441f05a1` командой `git archive --format=tar --prefix=<name>/ <commit> | gzip -n`. Архив Vkd3d 2.0 взят по URL и SHA-256, указанным в CMakeLists.txt закреплённого SDL_shadercross. Архивы содержат исходный код и скрипты сборки библиотек; общие параметры сборки SDL-компонентов находятся в release-manifest.json.

На Windows, Linux, macOS и Android библиотеки поставляются отдельными динамическими файлами. Совместимую изменённую библиотеку можно подставить под тем же именем в `runtimes/<rid>/native/` перед сборкой или в каталоге экспортированной игры, если его загрузчик и правила платформы допускают замену. Проверка `Test-LgplReplaceability.py` загрузила изменённые копии трёх Linux x64 библиотек из отдельного каталога; выполнение игры на других ОС этим не удостоверено.

На iOS и tvOS `libgme.a` и `libmpg123.a` статически компонуются при сборке конечного приложения. Их можно заменить в нативных файлах NuGet-пакета перед сборкой приложения: `buildTransitive`-цели подхватывают `*.a` из каталога RID. Та же проверка повторно связала изменённые архивы для всех шести Apple RID. Разработчик конечной игры отвечает за возможность её повторной компоновки с изменённой библиотекой и передачу необходимых материалов своим получателям. Наличие исходников и успешная пробная линковка пакета сами по себе не проверяют каждый экспорт игры.
